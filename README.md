# 📊 Python para Análise de Dados

 📌 Contexto e Objetivos

Este repositório tem como objetivo consolidar meus estudos em **Python aplicado à análise de dados**, abordando desde conceitos fundamentais até práticas utilizadas no mercado.

O foco principal é desenvolver habilidades analíticas utilizando bibliotecas populares e compreender como transformar dados em informações úteis para tomada de decisão.

### 🎯 Objetivos de Aprendizado

* Aprender manipulação de dados com **Pandas**
* Trabalhar com arrays e operações numéricas com **NumPy**
* Realizar análise exploratória de dados (EDA)
* Criar visualizações com **Matplotlib** e **Seaborn**
* Tratar e limpar dados reais
* Desenvolver pensamento orientado a dados

📖 Glossário

* **DataFrame** → Estrutura de dados tabular (linhas e colunas)
* **EDA (Exploratory Data Analysis)** → Análise inicial para entender os dados
* **Missing Values** → Dados ausentes
* **Outliers** → Valores fora do padrão
* **Feature Engineering** → Criação de novas variáveis
* **Dataset** → Conjunto de dados
